# Anushka Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` - Page structure and content
- `style.css` - Colors, layout, responsive design, and 3D background
- `script.js` - Mobile menu, scroll reveal, project modal, and contact form behavior
- `todo-app.html` - Working To-Do App project demo
- `todo-app.css` - To-Do App interface styles
- `todo-app.js` - To-Do App task logic, filters, and local storage

## How To Run

Open `index.html` in a browser to view the portfolio.

Open `todo-app.html` directly, or click **Open App** on the To-Do App card, to use the working task manager demo.

## Customize

- Replace `anushka@example.com` in `index.html` with your real email address.
- Update the project descriptions and skills to match your latest work.
- Add real project links when your GitHub or live demos are ready.
